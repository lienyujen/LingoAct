01 / CLASSROOM

一堂課，四種語言練習

活動由課程語言與級別出發，讓題目、標音和評量對應你的教學目標。

聽

聽說播音室

把文字或截圖轉成語音，派送聽力理解或朗讀練習；依教學設定使用相應的語音與標音。

說

看圖說寫

用現成圖片或 AI 生圖練習描述與敘事。題目會連同建議詞彙、句型一起送到學生端，保留教學原文。

讀

閱讀與測驗

依級別生成或處理文章，搭配生詞、語法說明與理解題；閱讀任務可使用 i+1、i+2 的難度設定。

寫

手寫與寫作

學生可在畫布書寫，也能拍照、上傳或貼上手寫圖片；寫作活動可搭配教師檢視與 AI 回饋。

也支援字詞卡、投票、問答、文字雲、討論板、抽籤、搶答，以及課末回饋與報表匯出。

02 / GET STARTED

從第一次開啟，到一堂完整的課

先設定自己的後端，再開始教學。課堂資料會存到你設定的 Supabase 專案。

  1. 01

    取得適合的教師版本

    向作者取得對應的 Windows 或 macOS 版本。Windows 解壓縮後執行資料夾內的程式；macOS 開啟 DMG，將 App 移到「應用程式」。

  2. 02

    連接自己的 Supabase

    在設定畫面填入 Supabase 專案網址或識別碼與 publishable key。若後端尚未建立，使用程式中的部署精靈建立資料表與 AI 功能。部署時依畫面提示提供存取權杖及所需的 AI 金鑰。

  3. 03

    選擇語言、標準與級別

    建立課程時先選教學語言與程度。華語版預設繁體，可切換簡體；簡體使用 HSK 與普通話，繁體使用原有的 TBCL／TOCFL 與華語教學設定。需要時再調整個別任務的級別。

  4. 04

    邀請學生掃碼加入

    開啟「加入課堂」的 QR Code。學生用瀏覽器加入並輸入姓名，不需安裝程式。若要外語介面，使用學生頁右下角的語言選單。

  5. 05

    派送活動，觀察學生回應

    選擇聽、說、讀或寫活動，準備材料後派送。學生頁會自動更新。看圖說寫的詞彙與句型會隨題目送出；切換介面語言不會翻譯這些練習材料。

  6. 06

    檢視回饋，保存課堂成果

    在教師端查看作答，依需要啟用分析或批改。課堂結束時收集 Exit Ticket，查看報告並匯出。AI 回饋請由教師檢視後用於教學。

把設定跟著資料夾帶走

Windows 將 .env 放在 EXE 同一個資料夾；macOS 放在 App 外面的同一個資料夾。複製整個資料夾即可帶走這些公開設定。更新程式時請保留自己的 .env。

只放 Supabase 網址、公開金鑰與學生端網址。Gemini、OpenAI 等私密金鑰留在後端；教師管理金鑰須另外設定。範例中的佔位內容請換成你自己的公開設定。

VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY
VITE_PUBLIC_APP_URL=https://lingo.ehuayu.org

軟體授權與雲端服務費用是兩回事。Supabase 與 AI 服務的額度、費用取決於你自己的帳號和用量。 Supabase · Gemini · OpenAI

03 / EDITIONS

選擇你的教學版本

各版本共用學生頁與活動資料格式，差別在教師端的語言、標準與活動配置。

華語教學版

預設繁體；可選簡體或 English。簡體使用 HSK，繁體使用 TBCL／TOCFL；English 可選三種標準。

簡體中文／HSK 版

固定簡體中文、HSK 與中國大陸標準普通話。學生仍可選擇外語介面。

NCACLS 版

面向中文學校的繁體華語教學版本，沿用華語文程度與標音設定。

英語教學版

以英語教學為主，提供對應的程度與聽說讀寫活動。

國語文教學版

以臺灣國語文教學為主，使用課綱階段與注音設定。

完整教學版

保留多種教學語言與活動，適合需要切換不同語言課程的教師。

課堂常見問題

學生需要安裝程式嗎？

不需要。教師使用桌面程式，學生透過手機、平板或電腦瀏覽器加入。

切換學生介面語言，會把中文練習也翻譯掉嗎？

看圖說寫的題目、詞彙與句型保留教學原文。部分閱讀詞義、語法說明及評核說明會在學生實際選擇外語時按需翻譯；其中的中文教學引用仍會保留。

題目沒有出現時怎麼辦？

先確認老師已派送完成，學生頁連線正常且使用新版。可重新整理一次載入最新版；若持續發生，請向教師回報活動類型及畫面，不要重複提交作答。

我可以使用自己的後端嗎？

可以。設定自己的 Supabase 專案即可；加入連結會帶上對應的公開連線資訊。私密 AI 金鑰不應出現在學生頁或 .env。
