01 / CLASSROOM

一堂课，四种语言练习

根据课程语言与级别安排活动，让题目、标音和评估服务于你的教学目标。

听

听说播音室

将文字或截图转成语音，发布听力理解或朗读练习，并采用与教学设置对应的语音和标音方式。

说

看图说写

用现有图片或 AI 生成的图片练习描述与叙事。题目会连同建议词语、句型一起发送给学生，并保留教学原文。

读

阅读与测验

根据级别生成或处理文章，搭配生词、语法说明与理解题。阅读任务可设置 i+1 或 i+2 的难度。

写

手写与写作

学生可以在画布上书写，也可以拍照、上传或粘贴手写图片。写作活动支持教师查看和 AI 反馈。

还支持词语卡、投票、问答、词云、讨论板、随机点名、抢答，以及课后反馈与报表导出。

02 / GET STARTED

从首次打开，到上完一堂课

先设置自己的后端，再开始教学。课堂数据会存入你设置的 Supabase 项目。

  1. 01

    获取合适的教师版本

    向作者获取对应的 Windows 或 macOS 版本。Windows 解压后运行文件夹内的程序；macOS 打开 DMG，将 App 移入“应用程序”。

  2. 02

    连接自己的 Supabase

    在设置页面填写 Supabase 项目网址或项目标识符及 publishable key。如果尚未建立后端，可使用程序中的部署向导建立数据表和 AI 功能，并按页面提示提供访问令牌及所需的 AI 密钥。

  3. 03

    选择语言、标准与级别

    创建课程时先选择教学语言与级别。华语版默认繁体，可切换简体。简体采用 HSK 与普通话，繁体沿用 TBCL／TOCFL 及原有的华语教学设置；也可以调整单个任务的级别。

  4. 04

    邀请学生扫码加入

    打开“加入课堂”二维码。学生通过浏览器加入并填写姓名，无需安装程序。需要外语界面时，使用学生页右下角的语言菜单。

  5. 05

    发布活动，查看学生回答

    选择听、说、读或写活动，准备材料后发布，学生页面会自动更新。看图说写的词语和句型会随题目一起发送；切换界面语言不会翻译这些练习材料。

  6. 06

    查看反馈，保存课堂成果

    在教师端查看作答，并根据需要启用分析或批改。下课时收集 Exit Ticket，查看报告并导出。AI 反馈应由教师审核后用于教学。

让设置跟着文件夹走

Windows 将 .env 放在 EXE 所在的文件夹；macOS 放在 App 外部的同一个文件夹。复制整个文件夹即可带走这些公开设置。更新程序时，请保留自己的 .env。

只填写 Supabase 网址、公开密钥和学生端网址。Gemini、OpenAI 等私密密钥保留在后端，教师管理密钥需另外设置。请将示例中的占位内容换成你自己的公开设置。

VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_PUBLISHABLE_KEY
VITE_PUBLIC_APP_URL=https://lingo.ehuayu.org

软件授权与云服务费用是两回事。Supabase 和 AI 服务的额度、费用取决于你自己的账号和用量。 Supabase · Gemini · OpenAI

03 / EDITIONS

选择适合你的教学版本

各版本共用学生页面和活动数据格式，区别在于教师端的语言、标准与活动配置。

华语教学版

默认繁体，可选简体或 English。简体采用 HSK，繁体采用 TBCL／TOCFL；English 可选择三种标准。

简体中文／HSK 版

固定简体中文、HSK 和中国大陆标准普通话。学生仍可选择外语界面。

NCACLS 版

面向中文学校的繁体华语教学版本，沿用华语文级别与注音设置。

英语教学版

以英语教学为主，提供对应的级别及听说读写活动。

台湾语文教学版

以台湾地区的母语语文教学为主，使用当地课程纲要阶段与注音符号。

完整教学版

保留多种教学语言与活动，适合需要切换不同语言课程的教师。

课堂常见问题

学生需要安装程序吗？

不需要。教师使用桌面程序，学生通过手机、平板或电脑浏览器加入。

切换学生界面语言，会把中文练习也翻译掉吗？

看图说写的题目、词语和句型保留教学原文。部分阅读词义、语法说明及评估说明会在学生实际选择外语时按需翻译，其中的中文教学引用仍会保留。

题目没有出现时怎么办？

先确认教师已完成发布，学生页面连接正常且使用新版。可刷新一次以加载最新版；如果问题持续，请向教师说明活动类型并提供画面，不要重复提交作答。

可以使用自己的后端吗？

可以。设置自己的 Supabase 项目即可，加入链接会带上对应的公开连接信息。私密 AI 密钥不应出现在学生页面或 .env 中。
